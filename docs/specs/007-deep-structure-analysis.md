# 007: 20~30대를 위한 깊은 사주 구조 분석

## 목적

기존 일간·대표 오행 중심 풀이에 십성, 지장간, 천간·지지 관계와 계절 정보를 추가한다. 계산 근거를 이용해 겉으로 보이는 모습과 내면의 동기, 의사결정, 일, 관계, 스트레스 반응의 연결을 20~30대가 읽기 좋은 구체적인 한국어로 설명한다.

## 결정된 내용

- 주요 사용자는 자신의 성향·일·관계·현재 방향을 깊게 분석하고 싶은 20~30대다.
- 초등학생 대상처럼 지나치게 단순하거나 귀여운 문장을 사용하지 않는다.
- 사주 용어는 사용할 수 있다. 용어가 나온 바로 다음 문장에서 일상적인 뜻을 풀어 설명한다.
- 설명을 길게 반복하기보다 서로 다른 계산 근거를 연결해 패턴과 긴장을 설명한다.
- 단순 오행 개수만으로 신강·신약, 격국, 용신을 확정하지 않는다.

## 추가 계산

### 십성

- 일간을 기준으로 년주·월주·일주·시주의 천간과 지장간에 해당하는 십성을 계산한다.
- 비견, 겁재, 식신, 상관, 편재, 정재, 편관, 정관, 편인, 정인을 모두 지원한다.
- 각 십성은 좋고 나쁨이 아니라 에너지를 쓰는 방식으로 설명한다.

### 지장간

- 각 지지 안에 들어 있는 숨은 천간을 순서대로 표시한다.
- 겉으로 드러난 천간과 지장간의 십성이 다르면 `겉으로 보이는 방식과 내면의 동기가 다를 수 있는 단서`로 제공한다.
- 지장간의 존재만으로 숨겨진 성격을 확정하지 않는다.

### 천간·지지 관계

- 네 기둥 안의 천간 합과 충을 계산한다.
- 지지의 합, 충, 형, 파, 해와 자형을 계산한다.
- 관계가 발견된 두 기둥, 글자, 관계 이름을 모두 저장한다.
- 관계 하나만으로 사건이나 인간관계 결과를 예측하지 않는다.

### 계절과 오행 참고 점수

- 월지로 태어난 계절과 계절의 중심 오행을 표시한다.
- 보이는 8글자, 지장간과 월지의 계절성을 합친 참고 점수를 제공한다.
- 점수는 비교를 돕는 서비스 기준이며 전통 명리의 신강·신약 판정이 아니라고 표시한다.

## 결과 화면

`내 사주의 구조` 상세 영역에 다음을 보여준다.

1. 계절과 중심 오행
2. 네 기둥의 천간 십성
3. 지지 속 지장간과 십성
4. 발견된 천간·지지 관계
5. 오행 참고 점수와 계산 기준

## Gemini 풀이 기준

- 계산된 구조만 전달하고 Gemini가 십성·지장간·관계를 새로 계산하지 않는다.
- `나 자신`의 여섯 주제는 겉과 속, 의사결정, 감정 표현, 반복 동기, 스트레스 반응, 성장 과제로 구성한다.
- `일과 돈`은 일의 동기, 실행 방식, 전문성, 협업, 돈을 다루는 방식, 소진 조건을 다룬다.
- `사랑과 관계`는 친밀감, 경계, 갈등, 표현, 반복 관계 패턴, 건강한 소통을 다룬다.
- 서로 다른 계산 근거가 같은 방향이면 반복 패턴으로, 다른 방향이면 내적 긴장이나 상황별 차이로 설명한다.
- 각 사주 용어를 처음 사용한 바로 다음 문장에서 쉬운 뜻을 설명한다.
- `당신은 원래`, `반드시`, `운명적으로`처럼 성격과 미래를 확정하지 않는다.
- 직장, 이직, 독립, 연애, 친구, 돈 관리, 휴식처럼 20~30대가 경험할 만한 예시를 사용한다.

## 말투 예시

> 월간에 정관이 있습니다. 정관은 정해진 기준과 책임을 의식하며 움직이는 방식을 뜻합니다. 그래서 역할이 분명한 환경에서는 안정적으로 실력을 보여줄 수 있지만, 기준이 모호한 상황에서는 무엇부터 맞춰야 할지 오래 살필 수 있습니다.

## 저장과 개인정보

- 계산된 구조만 저장하고 원본 생년월일·출생시간·성별은 저장하지 않는다.
- 기존 저장 결과에 구조 데이터가 없어도 계속 읽는다.
- Gemini에는 계산된 십성·지장간·관계·계절 정보만 전달한다.

## 완료 조건

1. 네 기둥의 천간·지장간 십성이 일간 기준으로 계산된다.
2. 천간 합·충과 지지 합·충·형·파·해가 근거 위치와 함께 표시된다.
3. 계절과 오행 참고 점수의 계산법이 화면에 보인다.
4. 풀이가 20~30대 수준의 구체적인 문장과 상황 예시를 사용한다.
5. 사주 용어 다음 문장에서 쉬운 뜻을 제공한다.
6. 기존 저장 결과가 계속 열리고 새 구조는 형식 검사를 통과한다.
7. 타입 검사, 자동 테스트, 빌드와 실제 화면 확인을 통과한다.

## 이번 Spec에서 제외

- 신강·신약의 확정 판정.
- 격국과 용신·희신 확정.
- 사주 구조만으로 정신건강, 질병, 직업 적합성이나 관계 결과를 진단하는 것.

## 구현·검증 상태

- 2026-09-23: 십성·지장간·천간합충·지지합충형파해·계절·오행 참고 점수를 계산하고 `내 사주의 구조` 화면에 표시했다.
- Gemini 기본 풀이와 살·귀인 풀이를 20~30대용 말투와 직장·이직·독립·연애·돈 관리 예시로 수정했다. 용어 다음 문장에서 일상적인 뜻을 설명하도록 요청한다.
- 타입 검사와 자동 테스트 55개, 배포용 빌드, 문서 공백 검사를 통과했다. 브라우저에서 구조·십성·관계·참고점수 영역을 확인했다.
- 실제 Gemini 응답이 새 말투와 깊이를 일관되게 지키는지는 아직 확인하지 않았다.
