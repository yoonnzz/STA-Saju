# 006: 사주 8글자와 오행 분포 한눈에 보기

## 목적

사용자가 자신의 사주팔자 여덟 글자를 결과에서 바로 찾고, 각 글자의 오행과 다섯 오행의 개수를 한눈에 비교한다.

## 범위와 기준

- 기존 `lib/saju` 계산 결과를 그대로 사용한다. 년주·월주·일주·시주를 각각 천간과 지지 두 글자로 표시하고, 한글 읽기와 각 글자의 오행을 함께 보여준다.
- 결과 상단에서 펼침 조작 없이 8글자와 오행 분포를 볼 수 있게 한다. 기존의 자세한 계산 기준 설명은 유지한다.
- 목·화·토·금·수를 고정된 순서의 막대로 표시한다. 막대 길이는 여덟 글자 중 해당 오행의 횟수이며, 숫자도 항상 함께 표시한다.
- 가장 많은 오행과 가장 적은 오행을 동률까지 빠짐없이 표시한다. 0개도 명확히 표시한다.
- 여기서 ‘적다’는 여덟 글자의 대표 오행 횟수 비교만 뜻한다. 사주 전체의 강약이나 개인의 능력·미래에 대한 판단으로 설명하지 않는다.
- 모바일에서도 네 기둥과 다섯 막대의 글자·수치를 읽을 수 있고, 색 없이도 정보가 전달되어야 한다.

## 확인 기준

1. 정상 계산 결과에서 네 기둥의 천간·지지 8글자와 한글 읽기, 각 글자의 오행이 일치한다.
2. 다섯 오행의 막대와 숫자가 계산값과 일치하고 합계가 8이다.
3. 최다·최소 동률 및 0개가 정확히 표시된다.
4. 기존 입력 오류, AI 해석, 저장 결과 복원 흐름을 깨지 않는다.
5. 타입 검사, 관련 자동 테스트, 빌드와 실제 화면을 확인한다.

## 검증 기록

- 2026-09-23: 결과 상단에 네 기둥의 8글자·한글 읽기·글자별 오행과 다섯 오행 막대·숫자·최다/최소 항목을 구현했다.
- 독립 테스트 담당이 8글자, 계산값과 막대 길이, 동률과 0개를 검증하는 테스트 3개를 추가했다. 전체 자동 테스트 46개, 타입 검사, 배포용 빌드, `git diff --check`가 통과했다.
- 로컬 브라우저에서 `2005-12-23 08:37` 입력 시 8글자와 목·화 각 1개, 토·금·수 각 2개를 확인했다. `1989-12-31` 입력 시 이전 결과가 사라지고 지원 범위 안내가 나왔다.
