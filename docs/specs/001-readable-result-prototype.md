# 001: 읽기 쉬운 사주 결과 시제품

## 목적

기존 계산 결과를 바탕으로 핵심 요약을 먼저 보여주고, 궁금한 내용만 펼쳐서 계산 근거와 용어를 읽게 한다. 현재 계산 규칙은 바꾸지 않는다.

## 이번 시제품의 범위

- 지원하는 양력 생년월일과 출생시간을 입력하면 기존 `calculate` 결과를 사용한다.
- 맨 위 요약에는 일간과 대표 오행 분포에서 가장 많이 나온 항목을 쉬운 말로 보여준다. 동률이면 동률이라고 표시한다.
- 펼쳐 보는 항목으로 일간의 뜻, 다섯 오행의 횟수, 네 기둥과 계산 기준을 제공한다.
- 각 설명에서 계산으로 확인한 사실과 전통적 상징에 대한 해석을 구분한다. 오행 횟수만으로 성격·미래·강약을 확정하지 않는다.
- 입력 오류가 나면 이전 결과를 지우고 이유를 보여준다.
- 작은 화면에서도 읽을 수 있고 키보드로 펼쳐 볼 수 있다.

## 이번 시제품에서 다루지 않는 것

- 공유 링크: 결과 보관 기간과 삭제 방식을 정하기 전에는 만들지 않는다. 출생 정보를 URL에 직접 넣는 임시 방식도 사용하지 않는다.
- 회원가입, 결제, AI 대화, 단정적인 운세·상담 문구.
- 계산 지원 범위 확장. 출생시간을 모르는 경우, 음력, 1990년 이전 날짜는 기존 제한을 따른다.

## 확인 방법

1. 유효한 입력을 넣으면 요약을 먼저 보고, 각 상세 항목을 펼쳐 숫자와 근거를 확인한다.
2. 오행 최댓값이 동률인 계산 결과도 특정 한 항목만 최고라고 잘못 표시하지 않는다.
3. 잘못된 날짜 또는 누락 입력은 안내를 보이고 이전 결과를 남기지 않는다.
4. 기존 사주 계산 테스트, 새 요약 테스트, 타입 검사와 실제 화면을 확인한다.

## 검증 기록

- `npm run check` 통과: 타입 검사와 자동 테스트 19개, 실패 0개.
- 브라우저에서 `2005-12-23 08:37`을 입력해 신사일주 요약과 최다 오행 동률(토·금·수 각 2번)을 확인함.
- 세 가지 상세 항목을 펼쳐 일간, 오행 5개, 네 기둥과 계산 기준을 확인함.
- `1989-12-31`을 입력했을 때 지원 범위 안내가 나오고 이전 결과가 사라지는 것을 확인함.
- 참가자의 직접 화면 확인은 아직 받지 않음.
