# 009: 결과 페이지와 공유 링크

## 목적

긴 사주 풀이를 탐색하기 쉬운 개별 페이지로 나누고, 로그인 사용자가 고정된 결과를 링크로 공유한다.

## 결정된 동작

- 해석 완료 또는 저장 결과 재방문 시 목차를 먼저 표시한다. 목차에는 핵심 요약, 다섯 풀이 링크, 전체 실천 조언을 둔다.
- 풀이 페이지는 `나 자신`, `일과 돈`, `사랑과 관계`, `삶의 흐름`, `살·귀인`으로 나눈다. 상단 메뉴로 목차와 다른 풀이로 이동한다.
- 로그인 사용자는 메뉴의 별도 `오늘의 운세` 페이지를 연다. 새 사주 입력도 별도 화면에서 시작한다.
- 공유 링크는 로그인 사용자가 계정에 저장한 정상 해석에서만 만든다. 공유 화면은 작성 당시 결과의 고정 사본이다.
- 공유할 때 입력한 별명만 공개한다. 출생 날짜·시간·성별, Google 이름, 오늘의 운세는 공개하지 않는다.
- 받는 사람은 로그인 없이 목차와 모든 풀이를 읽는다. 모든 공유 페이지 상단에 `내 사주 시작하기`를 둔다.
- 링크는 30일 후 만료되고 작성자가 먼저 삭제할 수 있다. 만료·삭제·잘못된 링크는 내용을 보여주지 않는다.

## 보안과 실패 조건

- 주소에는 생년월일이나 순차 ID 대신 추측하기 어려운 무작위 토큰을 사용하고 DB에는 토큰 해시만 저장한다.
- 공유 생성·목록·삭제는 서버에서 로그인 사용자를 확인하고 행 수준 보안으로 소유자를 제한한다.
- 익명 요청은 유효한 토큰의 최소 공유 자료만 서버를 통해 읽는다. 공유 테이블의 익명 직접 읽기는 허용하지 않는다.
- 저장되지 않은 해석, 형식이 잘못된 해석, 저장 오류는 공유 성공으로 표시하지 않는다.
- 공유 링크에 현재 계정의 운세나 다른 사용자의 최신 사주를 혼합하지 않는다.

## 검증 기준

1. 목차와 다섯 개별 URL이 새로고침 및 뒤로 가기 후에도 같은 해석을 표시한다.
2. 로그인 사용자에게만 오늘의 운세 메뉴와 공유 생성 기능이 보인다.
3. 공유 링크는 고정 결과를 30일 동안 읽고, 만료·삭제 후에는 읽지 못한다.
4. 작성자만 자신의 링크를 삭제하며 다른 사용자의 링크는 변경하지 못한다.
5. 공유 데이터와 주소에 원본 출생정보, 계정 정보, 비밀키, 오늘의 운세가 없다.
6. 관련 테스트, 타입 검사, 빌드, 기존 입력·계정 저장·운세 흐름을 검증한다.
