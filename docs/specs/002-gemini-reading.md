# 002: Gemini 사주 해석과 브라우저 저장

## 목적

기존 사주 계산 결과를 바탕으로 Gemini가 쉬운 말의 해석을 작성하고, 사용자가 나중에 같은 브라우저에서 다시 볼 수 있게 결과를 저장한다. AI와 주고받는 대화 기능은 만들지 않는다.

## 결정된 내용

- 사용할 모델 코드는 **`gemini-3.5-flash-lite`**로 고정한다. [Google 공식 모델 문서](https://ai.google.dev/gemini-api/docs/models/gemini-3.5-flash-lite)에서 이 코드를 확인했다. 다른 모델로 자동 대체하지 않는다.
- 사주 계산은 기존 `lib/saju`가 담당한다. Gemini에게 날짜 계산이나 네 기둥 산출을 맡기지 않는다.
- Gemini는 **해석 문구만** 작성한다. 계산으로 확인한 값과 그 값에 대한 해석을 화면에서 구분한다.
- 결과는 우선 브라우저의 `localStorage`에 저장한다. 이는 사용자의 브라우저 안에 남는 저장 공간으로, 다른 기기나 브라우저에 자동으로 전달되지 않는다.
- `GEMINI_API_KEY`는 서버의 환경변수로만 읽는다. 화면 코드, 브라우저 저장소, 공유 URL, Git에 넣지 않는다.

## 사용자 흐름

1. 사용자가 기존 화면에 양력 생년월일과 출생시간을 입력한다.
2. 서비스가 기존 계산 기능으로 사주 자료를 계산한다. 지원하지 않는 입력이면 계산·Gemini 요청을 중단하고 이유를 보여준다.
3. 사용자가 해석 요청을 누르면 진행 중임을 화면에 알린다. 처음 요청하기 전에 계산된 사주 자료가 Gemini에 전달된다는 점을 알린다.
4. 서버가 입력을 다시 검증·계산하고, Gemini에 필요한 **계산 결과만** 보낸다. 원본 생년월일·출생시간은 Gemini 요청에 포함하지 않는다.
5. 서버가 Gemini 응답의 형식과 계산 근거와의 연결을 확인한 뒤 화면에 돌려준다. 사용자는 핵심 요약을 먼저 보고 자세한 항목을 펼친다.
6. 유효한 해석 결과만 `localStorage`에 저장한다. 가장 최근 정상 결과 1개를 새로고침 뒤에도 다시 보여준다.

## Gemini 결과 계약

- **입력 근거:** 일간, 네 기둥, 대표 오행 분포와 기존 계산 기준. 필요 이상의 개인정보는 전달하지 않는다.
- **출력:** 20~30대가 읽기 좋은 구체적인 말의 핵심 요약과 세 가지 펼쳐 보는 항목: ① 성향·강점·주의할 점 ② 일·진로 ③ 관계. 각 항목에는 자세한 풀이, 생활 속 가상 예시 하나, 참조한 계산 항목, 어려운 용어의 짧은 설명을 포함한다. 최신 말투 기준은 Spec 007을 따른다.
- **작성 원칙:** 짧고 쉬운 문장을 쓰고 사주 용어는 처음 나올 때 일상적인 말로 풀어준다. 예시는 개념을 이해시키는 가상 상황임을 분명히 하며 실제 사용자에게 일어날 일처럼 단정하지 않는다. 누구에게나 같은 문장만 반복하지 않고, 계산 결과 밖의 사실이나 미래를 확정적으로 말하지 않는다. 의료·법률·재정 판단을 지시하지 않는다.
- **형식:** `핵심 요약`과 고정된 세 항목을 구분한 구조화된 결과로 받는다. 성향 항목은 강점과 주의할 점을 별도로 구분한다. 각 항목에는 `example` 문장과 계산 근거를 최소 1개 연결한다. 새 응답에서 예시가 빠지거나 형식·근거가 틀리면 사용하지 않는다. 이전에 저장된 정상 결과는 예시가 없어도 읽을 수 있게 유지한다.
- **해석 주제:** 성향·강점·주의할 점, 일·진로, 관계를 모두 포함한다.

## 실패와 재시도

- API 키가 없거나 서비스 호출이 실패·지연되면 이유를 알기 쉬운 문장과 재시도 버튼을 보여준다. 비밀키나 내부 오류 내용은 화면에 표시하지 않는다.
- Gemini 응답이 비어 있거나 형식이 틀리거나 계산 자료와 맞지 않으면 해석을 성공한 것처럼 보여주지 않는다.
- 실패해도 기존 사주 계산 결과는 그대로 볼 수 있다. 실패한 내용은 저장하지 않고, 이전에 저장된 정상 결과를 지우지 않는다.
- 같은 요청을 다시 눌렀을 때 중복 호출과 중복 저장을 막는다.

## 브라우저 저장과 공유의 경계

- `localStorage`에는 가장 최근 정상 결과 1개만 남긴다. 유효한 계산 결과와 해석 결과, 생성 시각, 데이터 형식 버전을 저장하고, 새 정상 결과가 생기면 이전 결과를 교체한다. 원본 생년월일·출생시간, API 키, 서버 오류 원문은 저장하지 않는다.
- 저장 데이터를 읽을 때 형식을 검사한다. 깨진 데이터는 결과로 표시하지 않고 다시 계산하도록 안내한다.
- 브라우저 데이터를 지우거나 다른 기기에서 열면 저장 결과가 보이지 않을 수 있음을 안내한다. 브라우저 저장을 비밀 보관함처럼 설명하지 않는다.
- PRD의 ‘링크 복사로 공유’는 별도 기능이다. `localStorage`만으로 다른 사람에게 같은 결과를 보여줄 수 없으므로 이 Spec에서는 구현하지 않는다. 출생 정보를 URL에 담는 임시 링크도 만들지 않는다.
- **저장 범위:** 최근 정상 결과 1개. 목록과 여러 결과 보관은 이번 범위에서 제외한다.

## 확인 기준

1. 정상 입력에서는 기존 계산값을 근거로 한 쉬운 핵심 요약과 세 항목이 표시되고, 각 항목에 ‘예를 들면’으로 시작하는 가상 사례가 보인다. 새로고침 후에도 최근 정상 결과 1개를 다시 볼 수 있다.
2. 잘못된 입력은 Gemini 호출 없이 안내한다.
3. API 키 누락, 호출 실패, 잘못된 응답 각각에서 가짜 해석을 만들지 않고 재시도할 수 있다.
4. 브라우저 개발자 도구와 생성 파일에서 API 키가 노출되지 않는다. Gemini 요청에 원본 생년월일·출생시간이 포함되지 않는다.
5. 기존 계산 테스트와 새 해석·저장 테스트, 실제 화면의 성공·실패·재시도를 확인한다.

## 이번 Spec에서 제외

- 회원가입, 결제, AI 대화, 다른 사람에게 열리는 공유 링크, 여러 기기 간 동기화.
- 배포 전에는 서버 측 호출 남용과 비용을 제한하는 방식을 별도로 점검한다.

## 구현·검증 상태

- 서버에서 `gemini-3.5-flash-lite`로 계산 결과만 보내고, 구조화된 해석을 검사해 돌려주는 기능을 구현함. 브라우저에는 최근 정상 결과 1개를 저장하고 다시 여는 기능을 구현함.
- 쉬운 문장과 생활 속 가상 예시를 요구하도록 Gemini 요청을 수정하고, 새 응답에서는 세 항목의 예시를 필수로 검사함. 화면에는 ‘예를 들면’ 영역을 추가함. 기존에 저장된 예시 없는 정상 결과는 계속 읽을 수 있음.
- `npm run check` 통과: 타입 검사와 자동 테스트 31개, 실패 0개. `npm run build` 통과.
- 모의 Gemini 응답으로 성공, API 키 누락, 잘못된 응답, 연결 실패, 잘못된 입력을 검사함. 인증·사용 한도·요청 형식 오류에는 내부 내용을 숨기고 조치 안내를 표시하도록 확인함. 브라우저에서 계산 결과와 해석 요청 버튼, 잘못된 날짜의 요청 차단을 확인함.
- 생성된 브라우저용 파일에서 실제 API 키 문자열이 발견되지 않음.
- **남은 검증:** 실제 Gemini 호출의 성공·실패 및 결과 저장 후 새로고침 복원. 샘플 출생정보에서 계산된 사주 자료를 Google에 보내는 시험 호출이 자동 승인 검토에서 거절되어 진행하지 못함. 사용자 승인을 받은 뒤 검증하고 완료로 표시할 것.
- 현재 열린 화면에서 AI 해석 요청 실패 안내가 관찰됨. 서버 기록에는 `/api/reading`의 502 응답이 보였으나, Google이 보낸 구체적인 실패 이유는 기록되지 않아 원인을 확정하지 못함.
- 2026-09-24 재배포: Gemini 살·귀인 구조화 스키마의 배열 길이 제약으로 Google API가 400을 반환하던 문제를 수정했다. 짧지만 유효한 월운·실천 문구도 허용하고 빈 문구와 계산 근거 불일치는 계속 거부한다.
- **PASS:** 타입 검사, 자동 테스트 56개, 배포용 빌드, 실제 로컬 Gemini 요청과 화면 표시. Vercel 프로덕션 `https://sta-saju.vercel.app`에서 커밋 `59e941b` 배포가 Ready이며, 공개 테스트 입력의 API 응답 200과 살·귀인 해설 19개, 화면 해설 생성 및 새로고침 후 최근 결과 복원을 확인했다.
- **NOT TESTED:** 로그인 계정의 DB 저장, 프로덕션에서 실패 후 같은 화면의 재시도 동작. 이 항목을 완료로 처리하지 않는다.
