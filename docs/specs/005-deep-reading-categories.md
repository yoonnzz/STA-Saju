# 005: 카테고리별 깊은 사주 풀이와 시기 흐름

## 목적

기존의 짧은 성향·진로·관계 풀이를 확장해, 사용자가 `나 자신`, `일과 돈`, `사랑과 관계`, `삶의 흐름`을 한 화면에서 자세히 읽는다. 삶의 흐름은 계산된 대운·세운·월운을 근거로 설명한다.

## 결정된 내용

- 큰 카테고리는 ① 나 자신 ② 일과 돈 ③ 사랑과 관계 ④ 삶의 흐름 ⑤ 전체 실천 조언으로 고정한다.
- 네 카테고리를 접어 두지 않고 한 화면에 순서대로 모두 보여준다.
- 모든 설명은 20~30대가 읽기 좋은 구체적인 한국어로 작성한다. 사주 용어를 사용하면 바로 다음 문장에서 일상적인 뜻을 설명한다. 이 말투 기준은 Spec 007이 기존 기준을 대신한다.
- 각 세부 주제에는 설명, 생활 속 가상 예시, 주의할 점 또는 실천 방법을 포함한다.
- 삶의 흐름에는 10년 단위 대운, 올해와 내년의 세운, 올해 12개월의 월운을 모두 포함한다.
- 입력에 성별을 추가한다. 대운 방향과 시작 시기를 계산하는 용도로만 사용한다.
- 대한민국 출생과 한국 표준시만 지원한다. 출생 도시는 입력하지 않고 진태양시 보정도 하지 않는다.

## 입력과 계산 기준

- 필수 입력: 양력 생년월일, 출생시간, 성별.
- 성별은 `남성`, `여성` 두 선택지를 제공하며 선택하지 않으면 계산하지 않는다.
- 기존 네 기둥 계산은 `lib/saju`가 담당하고 Gemini에게 계산을 맡기지 않는다.
- 대운은 `lunar-javascript@1.7.7`의 `EightChar.getYun(gender, 2)` 계산을 사용한다. `2`는 절기까지 남은 시간을 분 단위로 계산하는 라이브러리 방식을 뜻한다.
- 남성은 라이브러리 값 `1`, 여성은 `0`으로 전달한다. 년간의 음양과 성별을 조합한 순행·역행은 라이브러리 계산 결과를 사용한다.
- 화면과 Gemini에는 대운 시작 나이·연도, 순행·역행, 각 10년 구간의 간지와 연도를 제공한다.
- 아직 첫 대운이 시작되지 않은 어린 사용자는 오류로 막지 않고 `대운 시작 전` 준비 구간으로 표시한다.
- 세운은 서비스를 이용하는 해와 다음 해를 계산한다. 저장된 결과는 생성 당시의 기준 연도를 유지한다.
- 월운은 서비스를 이용하는 해의 12개월 간지를 계산한다. 전통 명리의 월 구분은 절기 기준임을 함께 표시한다.
- 사주 계산에는 여러 전통 방식이 있으므로 이 서비스가 선택한 기준을 화면에 밝힌다.

## 결과 구조

### 1. 나 자신

- 기본 성향
- 생각하고 결정하는 방식
- 감정을 표현하는 방식
- 강점과 재능
- 반복해서 조심할 점
- 스트레스 반응과 회복 방법

### 2. 일과 돈

- 잘 맞는 업무 방식
- 능력을 발휘하기 좋은 환경
- 공부하고 성장하는 방식
- 협업과 책임을 대하는 태도
- 돈을 대하는 태도와 소비·저축 성향
- 일과 돈에서 조심할 점

### 3. 사랑과 관계

- 호감과 애정을 표현하는 방식
- 관계에서 중요하게 여기는 것
- 친구·가족·연인과 가까워지는 방식
- 갈등이 생겼을 때의 반응
- 잘 맞는 소통 방법
- 관계에서 조심할 점

### 4. 삶의 흐름

- 현재 대운: 해당 10년 구간의 중심 주제와 준비할 점
- 올해 세운: 강조되는 주제, 기회로 활용할 점, 조심할 점
- 내년 세운: 올해와 달라지는 점과 준비할 행동
- 올해 1월부터 12월: 달마다 짧은 주제와 실천 조언

### 5. 전체 실천 조언

- 지금 활용할 강점
- 반복해서 조심할 습관
- 오늘부터 해볼 작은 행동 3개

## Gemini 결과 계약

- Gemini에는 원본 생년월일·출생시간·성별을 보내지 않는다. 계산된 네 기둥, 오행, 대운·세운·월운만 전달한다.
- `나 자신`, `일과 돈`, `사랑과 관계`에는 정해진 세부 주제를 빠짐없이 구조화해 받는다.
- `삶의 흐름`에는 현재 대운 1개, 올해·내년 2개, 올해 월운 12개를 구조화해 받는다.
- 시기별 문장은 실제 사건이나 성공·실패를 예언하지 않는다. 계산 기호를 바탕으로 돌아볼 주제와 선택 가능한 행동을 제안한다.
- 건강·법률·투자·재정 결정을 지시하거나 관계 결과를 보장하지 않는다.
- 계산 결과 밖의 사실을 지어내거나 성별에 대한 고정관념을 풀이에 사용하지 않는다.
- 응답 형식, 항목 수, 계산 근거가 맞지 않으면 정상 결과로 저장하거나 표시하지 않는다.

## 저장 호환성

- 새 결과에도 기존 저장 버전 `1`을 유지하되 추가 필드는 선택적으로 읽을 수 있게 한다. 기존에 저장된 짧은 풀이도 계속 표시한다.
- 새로 생성되는 결과에서는 깊은 카테고리와 삶의 흐름을 필수로 검사한다.
- 계산 결과에는 원본 생년월일·출생시간·성별 대신 계산된 시기 흐름만 저장한다.
- 로그인 사용자는 Spec 004에 따라 가장 최근 정상 결과 1개를 데이터베이스에 저장한다.

## 실패와 예외

- 성별을 선택하지 않으면 `대운 계산을 위해 성별을 선택해주세요.`라고 안내한다.
- 대운·세운·월운 계산에 실패하면 Gemini를 호출하지 않고 계산 오류를 보여준다.
- 현재 대운이나 올해 세운을 찾지 못하면 빈 흐름을 만들지 않고 요청을 중단한다.
- Gemini가 4개 카테고리, 두 해, 12개월 중 하나라도 빠뜨리면 저장하지 않고 재시도를 안내한다.
- 새 긴 풀이 생성이 실패해도 이전에 저장된 정상 결과는 지우지 않는다.

## 확인 기준

1. 생년월일·출생시간·성별을 입력하면 네 기둥과 대운·세운·월운이 함께 계산된다.
2. 성별에 따라 대운의 순행·역행과 간지 순서가 달라지는 기준 사례를 자동 테스트한다.
3. 결과 화면에 네 카테고리와 전체 실천 조언이 한 화면에 모두 보인다.
4. 삶의 흐름에 현재 대운, 올해·내년, 올해 12개월이 빠짐없이 보인다.
5. 각 카테고리는 쉬운 설명, 생활 예시, 실천 조언과 계산 근거를 포함한다.
6. 원본 생년월일·출생시간·성별이 Gemini 요청과 데이터베이스 저장 결과에 포함되지 않는다.
7. 기존에 저장된 짧은 풀이도 오류 없이 다시 볼 수 있다.
8. 타입 검사, 자동 테스트, 빌드와 실제 화면에서 입력·계산·표시·저장을 확인한다.

## 이번 Spec에서 제외

- 대한민국 밖 출생지와 도시별 진태양시 보정.
- 음력 입력, 출생시간을 모르는 경우, 1990년 이전 출생.
- 특정 사건, 수명, 질병, 합격, 투자 수익, 결혼 시기를 확정하는 예언.
- 전통 계산 방식 여러 개를 사용자가 비교·선택하는 기능.
