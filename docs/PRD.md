# 📋 기획서 (PRD): 내 사주를 이해하는 서비스

> 무엇을, 왜 만들지 정리한 문서입니다. 핵심 요약과 펼쳐 보는 근거는 시제품으로 구현했고, Gemini 해석은 구현 후 실제 호출 검증을 기다리고 있습니다. 공유 링크는 아직 구현하지 않았습니다.

작성일: 2026-09-23 / 작성자: 참가자 (이름 미정)

## 1. 풀고자 하는 문제

- **현재 방식:** 사용자는 생년월일과 출생시간을 입력해 기본 사주 결과를 보거나 기존 서비스의 풀이를 읽습니다. 시작 코드는 일주·일간·네 기둥을 계산해 보여줍니다.
- **불편한 점:** 풀이가 짧고 뻔하며, 어려운 용어를 설명하지 않고, 해석의 근거도 알기 어렵습니다.
- **원하는 모습:** 핵심 내용을 먼저 쉽게 파악하고, 궁금한 부분만 펼쳐 자세한 풀이·용어 뜻·해석 근거를 읽습니다.

## 2. 사용자

- **누가:** 자신의 사주를 자세히 알아보고 싶은 사람.
- **언제:** 자신의 사주를 확인하고 풀이를 깊게 읽고 싶을 때.
- **어디서:** 웹 브라우저. 모바일 사용 여부는 구현 전에 확인합니다.

## 3. 입력 자료

- **입력:** 현재 코드 기준 양력 생년월일과 출생시간. 두 항목이 모두 필요합니다.
- **개인정보:** 출생 날짜와 시간은 개인 정보에 해당할 수 있습니다. 공유 링크 주소 자체에 이 값을 노출하지 않고, 링크를 가진 사람이 결과를 볼 수 있음을 안내합니다.
- **아직 필요한 자료:** 자세한 풀이 문구, 용어 설명, 각 풀이와 계산 결과를 연결하는 기준. 문구 작성·검토 방식은 미정입니다.
- **현재 계산 제한:** 시작 코드는 1990-01-01 이후 양력 날짜와 출생시간을 아는 경우만 지원합니다. 최종 서비스에서도 이 제한을 유지할지는 미정입니다.

## 4. 핵심 기능: 이것만 되면 일단 성공

1. 생년월일과 출생시간을 입력하면 기존 계산 기능을 사용해 사주 결과를 얻습니다.
2. 결과 맨 위에 입력에 따라 달라지는 쉬운 말의 핵심 요약을 보여줍니다.
   네 기둥의 한자 8글자와 각 글자의 오행, 다섯 오행의 횟수 비교를 결과 상단에서 바로 확인할 수 있게 합니다. 횟수가 적거나 0개인 오행을 운명적 결핍으로 단정하지 않습니다.
3. 원하는 항목을 펼쳐 자세한 풀이를 읽을 수 있습니다. 풀이의 주제와 순서는 구현 전에 정합니다.
4. 어려운 용어에 쉬운 뜻을 붙이고, 해석마다 관련 계산 결과와 설명을 보여줍니다. 계산에서 확인한 사실과 해석을 구분합니다.
5. 결과 공유 링크를 복사해 보내면 받은 사람이 회원가입 없이 같은 결과를 열어볼 수 있습니다. 링크 소지자가 결과를 볼 수 있다는 안내를 제공합니다.

- **AI에게 맡길 것:** `gemini-3.5-flash-lite`가 계산된 사주 자료를 바탕으로 나 자신, 일과 돈, 사랑과 관계, 삶의 흐름을 초등학생도 이해할 수 있는 쉬운 말과 생활 속 예시로 풉니다. 삶의 흐름에는 계산된 대운·올해와 내년의 세운·올해 월운을 사용합니다. 사주와 시기 계산은 `lib/saju`가 담당하며, AI 대화 기능은 이번 범위에서 제외합니다. 자세한 기준은 Spec 002와 005에 있습니다.
- **사람이 확인할 것:** 풀이가 계산 근거와 맞는지, 쉬운 말인지, 공유되는 내용이 적절한지 서비스 제작자가 검토합니다.

## 5. 결과와 완료 조건

- **결과물:** `day09` 웹 서비스의 결과 화면. 기획서는 `day09/docs/PRD.md`에 둡니다.
- **정상 입력:** 지원하는 날짜와 시간을 넣으면 핵심 요약, 펼쳐 보는 상세 풀이, 용어 설명과 근거가 나옵니다. 복사한 링크를 다른 브라우저에서 열면 같은 결과가 보입니다.
- **입력 오류:** 날짜나 시간이 없거나 지원 범위 밖이면 이유를 알 수 있는 안내가 보이고 잘못된 결과는 표시하지 않습니다.
- **공유 오류:** 존재하지 않거나 사용할 수 없는 링크라면 결과 대신 안내를 보여줍니다. 링크의 보관 기간과 삭제 방식은 구현 전에 정합니다.
- **검증:** 요약과 풀이가 실제 계산 결과에 연결되는지, 용어가 이해되는지, 링크 주소에 출생 날짜·시간이 직접 담기지 않는지 확인합니다.

## 6. 이번 범위에서 제외하거나 나중에 정할 것

- **제외:** 별도의 회원가입 양식, 이메일·비밀번호 로그인, 결제, AI와 대화하는 기능. Google 계정 로그인은 Spec 003 범위로 추가합니다.
- **추후 결정:** 공유 결과 보관 기간과 삭제 방식, 출생시간을 모르는 경우, 음력 입력, 1990년 이전 날짜, 자세한 풀이의 주제와 작성 방식.
- **저장 방식:** 로그인하지 않은 사용자는 Gemini 해석의 최근 정상 결과 1개를 브라우저 `localStorage`에 저장합니다. Google 로그인 사용자는 최근 정상 결과 1개를 Supabase 데이터베이스에 저장해 다른 브라우저에서도 다시 볼 수 있습니다. 자세한 기준은 Spec 004에 있습니다.

## 8. 구현 단계와 이후 범위

- **현재 시제품:** 핵심 요약, 일간·오행·네 기둥의 펼쳐 보는 설명과 계산 근거를 확인합니다.
- **이후 구현 목표:** 더 깊은 풀이 문구와 검토 기준을 정하고, 안전한 결과 보관 방식을 마련한 뒤 공유 링크를 구현합니다.
- **실습 종료 시각과 남은 시간:** 미정. 완료 일정도 아직 정하지 않았습니다.

## 9. 첫 구현 목표

기존 사주 계산 결과 하나를 이용해, 결과 화면 맨 위에 계산 결과와 연결된 쉬운 요약을 보여주는 작은 버전을 먼저 확인합니다. 이 단계는 시제품에서 구현했습니다.
