# 📋 기획서 (PRD): 내 사주를 이해하는 서비스

대표 문구: **내 사주를 읽는 시간, 나를 이해하는 시작.**

> 무엇을, 왜 만들지 정리한 문서입니다. 핵심 요약과 펼쳐 보는 근거는 시제품으로 구현했고, Gemini 해석은 구현 후 실제 호출 검증을 기다리고 있습니다. 공유 링크는 아직 구현하지 않았습니다.

작성일: 2026-09-23 / 작성자: 참가자 (이름 미정)

## 1. 풀고자 하는 문제

- **현재 방식:** 사용자는 생년월일과 출생시간을 입력해 기본 사주 결과를 보거나 기존 서비스의 풀이를 읽습니다. 시작 코드는 일주·일간·네 기둥을 계산해 보여줍니다.
- **불편한 점:** 풀이가 짧고 뻔하며, 어려운 용어를 설명하지 않고, 해석의 근거도 알기 어렵습니다.
- **원하는 모습:** 핵심 내용을 먼저 쉽게 파악하고, 궁금한 부분만 펼쳐 자세한 풀이·용어 뜻·해석 근거를 읽습니다.

## 2. 사용자

- **누가:** 자신의 사주를 자세히 알아보고 싶은 사람.
- **언제:** 자신의 사주를 확인하고 풀이를 깊게 읽고 싶을 때.
- **어디서:** 웹 브라우저. 모바일 사용 여부는 구현 전에 확인합니다.

## 3. 입력 자료

- **입력:** 현재 코드 기준 양력 생년월일과 출생시간. 두 항목이 모두 필요합니다.
- **개인정보:** 출생 날짜와 시간은 개인 정보에 해당할 수 있습니다. 공유 링크 주소 자체에 이 값을 노출하지 않고, 링크를 가진 사람이 결과를 볼 수 있음을 안내합니다.
- **아직 필요한 자료:** 자세한 풀이 문구, 용어 설명, 각 풀이와 계산 결과를 연결하는 기준. 문구 작성·검토 방식은 미정입니다.
- **현재 계산 제한:** 시작 코드는 1990-01-01 이후 양력 날짜와 출생시간을 아는 경우만 지원합니다. 최종 서비스에서도 이 제한을 유지할지는 미정입니다.

## 4. 핵심 기능: 이것만 되면 일단 성공

1. 생년월일과 출생시간을 입력하면 기존 계산 기능을 사용해 사주 결과를 얻습니다.
2. 결과 맨 위에 입력에 따라 달라지는 쉬운 말의 핵심 요약을 보여줍니다.
3. 결과 목차에서 원하는 항목의 개별 페이지로 이동해 자세한 풀이를 읽을 수 있습니다.
4. 어려운 용어에 쉬운 뜻을 붙이고, 해석마다 관련 계산 결과와 설명을 보여줍니다. 계산에서 확인한 사실과 해석을 구분합니다.
5. 결과 공유 링크를 복사해 보내면 받은 사람이 회원가입 없이 같은 결과를 열어볼 수 있습니다. 링크 소지자가 결과를 볼 수 있다는 안내를 제공합니다.
6. Google 로그인 사용자는 매일 자신의 오늘의 운세를 확인합니다. Gemini가 한 줄 요약과 일·돈·관계·실천 팁을 작성합니다. 구체적인 사용자 흐름과 미정 사항은 아래 11절과 Spec 008에 정리합니다.

- **AI에게 맡길 것:** `gemini-3.5-flash-lite`가 계산된 사주 자료를 바탕으로 나 자신, 일과 돈, 사랑과 관계, 삶의 흐름을 20~30대가 읽기 좋은 구체적인 말과 생활 예시로 풉니다. 사주 용어는 사용할 수 있지만 바로 다음 문장에서 일상적인 뜻을 설명합니다. 삶의 흐름에는 계산된 대운·올해와 내년의 세운·올해 월운을 사용합니다. 살·귀인은 서비스 규칙집 43개를 앱이 모두 검사하고, Gemini는 발견된 항목의 긍정적·어려운 발현 조건과 활용 행동만 설명합니다. 사주·시기·살·귀인·십성·지장간·합충형파해 계산은 `lib/saju`가 담당하며, AI 대화 기능은 이번 범위에서 제외합니다. 자세한 기준은 Spec 002, 005, 006, 007에 있습니다.
- **사람이 확인할 것:** 풀이가 계산 근거와 맞는지, 쉬운 말인지, 공유되는 내용이 적절한지 서비스 제작자가 검토합니다.

## 5. 결과와 완료 조건

- **결과물:** `day09` 웹 서비스의 결과 목차와 개별 풀이 화면. 기획서는 `day09/docs/PRD.md`에 둡니다.
- **정상 입력:** 지원하는 날짜와 시간을 넣으면 핵심 요약, 펼쳐 보는 상세 풀이, 용어 설명과 근거가 나옵니다. 복사한 링크를 다른 브라우저에서 열면 같은 결과가 보입니다.
- **입력 오류:** 날짜나 시간이 없거나 지원 범위 밖이면 이유를 알 수 있는 안내가 보이고 잘못된 결과는 표시하지 않습니다.
- **공유 오류:** 존재하지 않거나 사용할 수 없는 링크라면 결과 대신 안내를 보여줍니다. 링크의 보관 기간과 삭제 방식은 구현 전에 정합니다.
- **검증:** 요약과 풀이가 실제 계산 결과에 연결되는지, 용어가 이해되는지, 링크 주소에 출생 날짜·시간이 직접 담기지 않는지 확인합니다.

## 6. 이번 범위에서 제외하거나 나중에 정할 것

- **제외:** 별도의 회원가입 양식, 이메일·비밀번호 로그인, 결제, AI와 대화하는 기능. Google 계정 로그인은 Spec 003 범위로 추가합니다.
- **추후 결정:** 공유 결과 보관 기간과 삭제 방식, 출생시간을 모르는 경우, 음력 입력, 1990년 이전 날짜, 자세한 풀이의 주제와 작성 방식.
- **저장 방식:** 로그인하지 않은 사용자는 Gemini 해석의 최근 정상 결과 1개를 브라우저 `localStorage`에 저장합니다. Google 로그인 사용자는 최근 정상 결과 1개를 Supabase 데이터베이스에 저장해 다른 브라우저에서도 다시 볼 수 있습니다. 자세한 기준은 Spec 004에 있습니다.

## 8. 구현 단계와 이후 범위

- **현재 시제품:** 핵심 요약, 일간·오행·네 기둥의 펼쳐 보는 설명과 계산 근거를 확인합니다.
- **이후 구현 목표:** 더 깊은 풀이 문구와 검토 기준을 정하고, 안전한 결과 보관 방식을 마련한 뒤 공유 링크를 구현합니다.
- **실습 종료 시각과 남은 시간:** 미정. 완료 일정도 아직 정하지 않았습니다.

## 9. 첫 구현 목표

기존 사주 계산 결과 하나를 이용해, 결과 화면 맨 위에 계산 결과와 연결된 쉬운 요약을 보여주는 작은 버전을 먼저 확인합니다. 이 단계는 시제품에서 구현했습니다.

## 11. 오늘의 운세 개선 기획 (Spec 008)

### 해결할 문제와 대상

- 사용자는 긴 사주 해석을 매일 다시 읽는 대신, 오늘 하루에 적용할 만한 짧고 개인화된 내용을 확인하고 싶습니다.
- **대상은 로그인 사용자**입니다. 비회원에게 오늘의 운세를 제공하지 않습니다.
- 계정에 저장된 최근 사주 자료를 개인화 근거로 사용합니다. 저장된 사주가 없는 로그인 사용자는 기존 사주 입력과 해석 저장으로 안내합니다.

### 사용자가 볼 결과 — 확정

- Gemini가 **매일 개인별 문장**을 작성합니다.
- 화면에는 **한 줄 요약, 일, 돈, 관계, 실천 팁**을 구분해 보여줍니다.
- 문구는 가능한 행동과 자기 점검에 도움이 되게 쓰며, 특정 사건·수입·인연이 반드시 생긴다고 단정하지 않습니다.
- 계산된 사실(오늘의 일진, 사용자 사주와의 관계)과 Gemini의 해석을 화면에서 구분합니다.

### 이용 흐름

1. 사용자가 Google로 로그인합니다.
2. 계정에 저장된 사주가 있으면 오늘의 운세 영역에서 운세를 요청합니다. 저장된 사주가 없으면 기존 사주 입력과 해석 저장으로 안내합니다.
3. 매일 한국 시간 오전 8시대 예약 작업이 그날 운세를 미리 만듭니다. 오전 9시까지 준비하는 것이 목표입니다. 예약 작업에서 누락된 사용자나 오전 8시 이후 처음 결과를 저장한 사용자는 운세 버튼을 눌렀을 때 생성합니다.
4. 서버가 현재 날짜의 일진과 저장된 사주의 관계를 계산하고, Gemini에는 계산 결과만 전달합니다. 출생 날짜·시각, 성별, 계정 정보는 전달하지 않습니다.
5. Gemini의 결과 형식을 검사한 후 표시합니다. 같은 날짜에는 문장을 고정하고, 다음 날짜에는 새 운세로 교체합니다. 지난 날짜의 운세는 보관하거나 보여주지 않습니다.
6. 호출·형식·저장에 실패하면 실패 이유와 재시도 방법을 보여줍니다. 실패한 내용을 임시 운세로 바꾸지 않습니다.

### 완료 판단 기준

| 상황 | 기대 결과 |
|---|---|
| 로그인했고 계정에 사주가 저장됨 | 한 줄 요약과 일·돈·관계·실천 팁, 계산 근거가 표시됨 |
| 같은 날짜에 다시 확인 | 이미 만든 결과를 안정적으로 다시 볼 수 있음 |
| 다음 날짜에 확인 | 새 날짜를 명확히 표시하고 새 운세를 확인할 수 있음 |
| 로그아웃 상태 또는 저장된 사주 없음 | 운세 대신 로그인 또는 사주 저장 안내가 표시됨 |
| Gemini 오류·잘못된 응답·저장 오류 | 성공처럼 표시하지 않고 재시도할 수 있음 |
| 다른 계정으로 접속 | 이전 계정의 운세가 보이지 않음 |

### 확정된 운영 기준

- 하루는 **한국 표준시 자정**에 바뀝니다. `오늘의 운세 보기` 버튼을 눌러 준비된 결과를 표시합니다.
- 같은 날 운세는 고정하며, 지난 운세는 보관하지 않습니다. 사용자별 오늘 결과 1개만 유지합니다.
- 현재 서비스가 보관하는 계정의 최근 정상 사주 결과 1개를 기준으로 합니다. 같은 날 그 사주가 바뀌면 새 사주 기준으로 운세를 교체합니다.
- Vercel 무료 플랜의 예약 작업은 지정한 시각부터 한 시간 안에 시작될 수 있으므로 오전 8시대에 실행하도록 설정합니다. 예약 작업이 실패하거나 사용자가 그 뒤에 사주를 저장하면 버튼에서 생성합니다.
- 예약 실행에는 서버 전용 Supabase 비밀키와 `CRON_SECRET` 환경변수가 필요합니다. 두 값은 코드와 브라우저에 넣지 않습니다.

### 범위 밖

- 푸시 알림, 이메일 발송, 행운 점수·색상, 사용자끼리 운세 공유, 비회원 운세, AI 대화.

## 12. 결과 탐색과 공유 (Spec 009)

- 긴 결과를 목차와 `나 자신`, `일과 돈`, `사랑과 관계`, `삶의 흐름`, `살·귀인` 개별 페이지로 나눈다. 각 풀이 페이지 상단의 메뉴로 이동한다.
- 새 해석을 완성하거나 저장된 해석으로 다시 방문하면 결과 목차를 먼저 보여준다. 목차에는 핵심 요약과 전체 실천 조언을 둔다. 새 사주 입력은 별도 버튼으로 연다.
- 로그인 사용자의 상단 메뉴에는 별도 `오늘의 운세` 페이지를 제공한다.
- 로그인 사용자만 공유 링크를 만든다. 링크를 받은 사람은 로그인 없이 공유 당시의 고정된 목차와 다섯 풀이를 읽고, 상단 `내 사주 시작하기`로 자기 입력을 시작한다.
- 공유할 때 별명을 직접 입력한다. Google 계정 이름, 원본 생년월일·출생시간·성별, 오늘의 운세는 공유하지 않는다.
- 공유 링크는 30일 후 만료되며 만든 사람이 그전에 삭제할 수 있다. 새 사주를 계산해도 기존 공유 내용은 바뀌지 않는다.
